# Modern Survey Themes

Modern Survey Themes gives REDCap public surveys a fresh, modern look directly from the Survey Settings page. It uses mostly native REDCap features and Custom CSS to style your forms, giving you clean card layouts, rounded inputs, nicer buttons, modern fonts, and backgrounds with virtually no overhead when pages load. Client-side JavaScript is only loaded when needed to style and handle autocomplete dropdowns.

## A Small Warning

This EM was tested and built on REDCap 17.4.0. If you are on or upgrade to a version of REDCap that changes the CSS styling of the survey pages then this EM might incorrectly style your survey. 

## Installing

You can install the module from the REDCap EM repo or drop it directly in your modules folder (i.e. `redcap/modules/modern_survey_themes_v1.0.0`).
